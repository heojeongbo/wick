# Contributing

Bug reports and feature requests are welcome. Code is not.

Pull requests are restricted to collaborators. This is not about the quality of
anybody's patch — it is that a change here has to come with the reasoning that
made it, written next to it, and that reasoning is easier to write than it is to
review at second hand. An issue that says what went wrong is worth more to this
repository than a diff that fixes it.

## A useful issue

Describe the problem, not the fix. What you expected, what happened instead, and
the smallest configuration that shows the difference.

For anything that carries a file: say which sink, how big the file was, and what
`wick status` says about it afterwards. A carry that failed and a carry that was
never attempted look the same from the outside, and the journal is what tells
them apart.

## Security

Do not open an issue for a vulnerability. Use GitHub's private security advisory
form on this repository, which is under **Security → Report a vulnerability**.
